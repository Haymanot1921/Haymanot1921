### ⚠️ One important thing about the animations

The **typing animation** at the top will work immediately because it is an externally hosted SVG.

The **contribution snake** is different. This part:

```markdown
<img src="https://raw.githubusercontent.com/Haymanot1921/Haymanot1921/output/github-contribution-grid-snake.svg" />
```

requires a GitHub Action to generate the animation. If you haven't configured it yet, that section will initially show nothing.

You can create:

```text
Haymanot1921
│
├── README.md
│
└── .github
    └── workflows
        └── snake.yml
```

with a GitHub Action that automatically generates the snake every day.
