## 🚀 Featured Project

### 🍽️ MenuGo — Digital Menu SaaS Platform

A QR-code-based digital menu and restaurant management platform designed
to help restaurants manage menus, tables, orders, staff, and restaurant
operations digitally.

**Main technologies:**

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL
- Sequelize
- JWT Authentication
- Socket.IO
- Redis

**Key features:**

- 📱 QR Code Digital Menu
- 🍔 Menu and Category Management
- 🪑 Restaurant Table Management
- 🛒 Customer Ordering
- 👨‍🍳 Kitchen Order Management
- 👨‍💼 Restaurant Administration
- 👥 Role-Based Access Control
- 📊 Analytics
- 🔐 Authentication and Security
- 🏢 Multi-Tenant Architecture
